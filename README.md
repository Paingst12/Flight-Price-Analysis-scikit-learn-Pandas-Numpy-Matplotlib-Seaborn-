## Project: Flight Price Analysis ## 
   - File: Flight Price Analysis.ipynb  
   - Objective: 
     Analyze flight pricing data to identify key factors influencing ticket prices and extract actionable insights.  
   
   - Key Analysis:  
     - Data Cleaning and Handling Missing Values  
     - Identifying and Managing Outliers  
     - Analyzing the Distribution of Flight Prices  
     - Visualizing Price Trends by Airline, Source, Destination, and Travel Duration  

   
   - Dependencies:  
     - pandas  
     - numpy  
     - matplotlib  
     - seaborn  
     - scikit-learn  
     
   - Usage Instructions:  
     1. Ensure all dependencies are installed using the command:  
        ```
        pip install -r requirements.txt
        ```
     2. Open the Jupyter Notebook file `Flight Price Analysis .ipynb` located in the folder.  
     3. Run each cell sequentially to execute the analysis.
